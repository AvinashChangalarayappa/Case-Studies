# Power BI Case Studies

A collection of business intelligence case studies I completed. Each one shows how I turn raw data into clear, decision-ready dashboards, from data modelling and DAX measures to report design and storytelling.


## How to View

The reports are saved as `.pbix` files and can be opened with [Power BI Desktop](https://powerbi.microsoft.com/desktop/), which is free on Windows.

## Tools

Power BI Desktop · Power Query · DAX · Excel
